# AI HID CTRL icon

Created 2026-10-13. White pointer with cyan hardware-control traces and an orange Flipper accent on a dark rounded tile. Text-free artwork; transparency preserved outside the tile.

- [Windows ICO](ai-hid-ctrl-v1.ico): embedded 16, 24, 32, 48, 64, 128 and 256 px images, all decoded and size-verified.
- [PNG master](ai-hid-ctrl-v1.png): original generated artwork, 1254 × 1254, RGBA.

Artwork generated with the built-in image-generation tool; ICO exported with Pillow. Mac integration is installed in version 0.4.1 build 6 using the native [ICNS resource](../../mac/AppIcon.icns). See [installation and qualification record](../../docs/Icon-Installation-v041.md). The earlier design-only checkpoint did not modify the app; this installation changes its ad-hoc signature and required the existing Bluetooth grant to be refreshed; owner authentication and reconnect/Stop qualification are now complete.
